# 🍽️ FinalMealMate

FinalMealMate is a full-stack meal management web application designed to make meal planning and food management simple, convenient, and user-friendly.

## 🚀 Features

* 👤 User registration and login
* 🍱 Meal and food management
* 🔍 Search and browse meals
* 📋 View and manage meal information
* 💻 Interactive and responsive user interface
* 🗄️ Database integration
* 🔐 User authentication

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python
* **Database:** SQL
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/aishugubyad-byte/FinalMealMate.git
```

### 2. Open the project

```bash
cd FinalMealMate
```

### 3. Install required dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Open the local URL shown in the terminal in your browser.
